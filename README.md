# Smart Task Organizer
A Python program that helps users manage their daily tasks efficiently.

## Features
- Add new tasks
- View all tasks
- Delete a task
- Exit the program

## How to Run
1. Make sure you have Python installed on your computer.
2. Open your terminal or command prompt.
3. Navigate to the folder containing the Python file.
4. Run the program with:

```bash
python task_organizer.py
```

## Usage
- The program will display a menu with options to add, view, or delete tasks.
- Follow the on-screen prompts to manage your tasks.

## Notes
- Tasks are stored temporarily in memory. Closing the program will clear all tasks.
- Ensure to enter valid numbers when deleting tasks.
